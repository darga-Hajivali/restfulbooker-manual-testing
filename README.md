# Restful Booker Manual API Testing

## Project Overview
This project contains manual API testing for Restful Booker APIs using Postman.

The project includes:
- Positive test scenarios
- Negative test scenarios
- API validations
- Postman collections
- Screenshots
- API analysis notes
- Bug reporting practice

---

## Tools Used
- Postman
- Swagger/OpenAPI
- GitHub

---

## APIs Covered
### AUTH APIs
- POST Auth - Valid Credentials
- POST Auth - Invalid Password
- POST Auth - Blank Username
- POST Auth - Blank Password

---

## Validations Performed
- Status code validation
- Response body validation
- Token validation
- Error message validation
- Response time validation
