# Update Booking API Analysis

## Endpoint
PUT /booking/{id}

## Purpose
Updates existing booking details.

## Headers
- Content-Type: application/json
- Cookie: token

## Tools Used
- Postman
- Swagger/OpenAPI
- GitHub

---

# Positive Scenario - Valid Booking Update

## Request
Valid updated booking payload provided with authentication token.

## Expected Behavior
Booking should be updated successfully.

## Actual Behavior
Booking updated successfully.

## Validations
- Status code validation
- Updated firstname validation
- Updated price validation
- Response body validation

## Observation
PUT API successfully updated complete booking details.
